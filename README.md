## ✨ Core Features

1. **📊 Realtime Daily Balance & Deficit Detection**
   - Automatically computes remaining daily balance (**Income - Expenses - Debts**).
   - Accurately highlights negative deficit balances in soft red when debts exceed income.

2. **🎯 Multi-Savings Pockets & Financial Goals**
   - Manage multiple independent savings pockets alongside your Main Savings.
   - Set targets, track milestone percentages, and customize pocket colors with HSL precision.
   - Quick deposit, quick withdraw, and guarded inter-pocket transfers.

3. **💳 Debt & Liability Management**
   - Record active debts with lenders, nominals, due dates, and notes.
   - Quick payment modal that links directly to savings pockets and logs expense transactions automatically.

4. **⚡ Quick Transaction Logging (Income & Expense)**
   - Instant modal sheet with iconic categories and pocket allocation.
   - Fast, responsive numeric keypad; saves to local SQLite database in seconds.

5. **🌓 Adaptive Themes & Color System**
   - System auto-switching, permanent Light mode, or permanent Dark mode.
   - Specially calibrated green palette: darker and deeper in light mode for sharp readability, brighter and vibrant in dark mode for soft glowing clarity.

6. **📈 7-Day Expense Bar Chart**
   - Smooth animated bar chart powered by FlChart with horizontal grid lines.
   - Daily breakdown identifying spending trends and highest spending days.

7. **📸 Profile & Interactive Photo Cropping (Zero Lag)**
   - Capture or select avatar photos from Camera or Gallery.
   - Built-in interactive cropper with rotation and smooth gestures running fluidly up to 144Hz.
   - Interactive calendar birth date picker with auto-computed age and youth protection guard.

8. **🔍 Flexible History & Search by Pocket**
   - Filter transactions (*All*, *Income*, *Expense*, or by specific *Savings Pocket*).
   - Realtime instant search by title, category, or pocket name.
   - Swipe-to-delete action with confirmation.

9. **🔒 Local SQLite Storage**
   - Device-local SQLite database (`simpanan.db`).
   - Android Keystore encrypted preferences.
   - Zero telemetry, no third-party analytics, no tracking, and no advertisements.
