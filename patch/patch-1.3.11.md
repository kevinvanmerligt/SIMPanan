## 🎯 Ringkasan Pembaruan (Release Summary)

Pembaruan **Patch v1.3.11** menghadirkan penyempurnaan personalisasi profil pengguna, otomatisasi validasi umur, serta fleksibilitas warna kantong tabungan:

1. **🎂 Pemilih Tanggal Lahir & Hitung Umur Otomatis (Birth Date Picker & Auto Age):**
   - Menggantikan input manual angka usia dengan pemilih tanggal kalender interaktif.
   - Aplikasi secara otomatis menghitung umur pengguna dari tanggal lahir yang dipilih dan menampilkan label umur secara real-time.

2. **🔒 Penguncian Pekerjaan Usia di Bawah 18 Tahun (Under-18 Occupation Lock):**
   - Apabila umur pengguna hasil perhitungan di bawah 18 tahun, pilihan pekerjaan pada profil otomatis terkunci khusus untuk opsi **"Pelajar"**.
   - Dilengkapi indikator badge visual dan ikon gembok proteksi untuk memastikan profil sesuai usia.

3. **👤 Placeholder Nama Lengkap Elegan:**
   - Kolom nama lengkap kini menggunakan teks placeholder *"Pengguna"* yang rapi di dalam form input.
   - Memudahkan pengguna mengetik nama baru secara langsung tanpa perlu menghapus nilai default terlebih dahulu.

4. **🎨 Pemilih Warna Kustom HSL untuk Tabungan (Custom HSL Color Palette):**
   - Fitur baru pembuatan warna aksen kantong tabungan secara manual menggunakan kontrol HSL (Hue, Saturation, Lightness).
   - Dilengkapi kontrol slider responsif, kode hex warna aktif, dan pratinjau langsung, sambil tetap mempertahankan pilihan warna rekomendasi bawaan.

5. **📦 Ukuran File Terkompresi Ramping (~20–22 MB):**
   - Kompilasi rilis native Android arm64 yang ringan, hemat ruang penyimpanan, dan cepat dipasang.
